# Contributing

This repository accepts corrections to public Grabblist MCP integration metadata, client setup examples, and tool documentation.

For product bugs or feature requests, use https://grabbitapp.com/contact or the authenticated `send_feedback` MCP tool.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not open a public issue.

## Documentation changes

1. Create a focused branch.
2. Change only public integration files.
3. Run `python3 scripts/validate_public_repo.py`.
4. Open a pull request describing the externally visible correction.

Do not commit credentials, user data, screenshots containing personal records, private service code, or deployment configuration.
